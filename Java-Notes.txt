What is garbage collector ?
 objects are created in heap memory. 
 When an object is no longer referenced by any part of the program, 
 it becomes eligible for garbage collection, and the JVM removes it to free memory.

 It works :
   Objects are created → stored in heap
   References point to objects
   When references are removed → object becomes unreachable
   GC identifies and deletes such objects
  
   Ex: class Test{
        p s v main(String[] args){
           Test t=new Test();
           Test t1=new Test();
            t=null;  //object eligible for gc
            t1=null;
         }
      }

1. Mark

Identifies reachable and unreachable objects

2. Sweep

Removes unreachable objects

3. Compact

Rearranges memory to avoid fragmentation

### JAVA SERVLETS :

1. We initialize the servlet by calling ``init ()`` Method
2. The servlet calls the ``Service ()`` method for processing the client Request.
3. We can terminate the entire server ``destroy ()`` method.
### 1. ``init () ``:
 called ``only once`` when your servlet is initialized .
- called once (Initial setup)

`Syntax :`
``` ini()
   public void init () throws ServletException {
      // Statements ;
   }
```
### 2. `Service ()` :

-It's first method that gets called by the servlet container (like Apache tomcat ) whenever a client sends a request .
- `Called Multiple time Handled Request`
-The service checks the Http Method (Get, Post, Put, Delete).

``Syntax :``

``public void service(ServletRequest request,ServletResponse response)throws ServletException,IOException {}

1.  `doGet () `: Getting the data :

`Syntax :`

`public void doGet(ServletRequest request,Servlet Response) throws ServletException,IoException{ }`

2. `doPost () `: Inserting the data

`Syntax :`

`public void doPost(ServletRequest request,Servlet Response) throws ServletException,IoException{ }`

3. `doPut () `:  Update the data

	`Syntax :`

`public void doPut(ServletRequest request,Servlet Response) throws ServletException,IoException{ }`

4. doDelete () : Deletion purpose 

`Syntax :`

`public void doPut(ServletRequest request,Servlet Response) throws ServletException,IoException{ }`

### 3 . `destroy ()` :

If you want to terminate the entire java servlet 

-`called once (Clean Up)`

`Syntax :`

`public void destroy {}`
